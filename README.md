# ShellBook - Цифровой читательский дневник


##  О проекте

**ShellBook** - это веб-приложение для ведения читательского дневника, созданное для тех, кто хочет систематизировать свои впечатления от прочитанных книг в электронном виде.

###  Ключевые особенности

-  **Чтение книг** - встроенная читалка с текстами из общественного достояния
-  **Умные заметки** - добавляйте мысли с автоматическим сохранением цитат
-  **Закладки** - отмечайте важные места в тексте
-  **Коллекции** - систематизируйте книги по категориям
-  **Пользовательские коллекции** - создавайте свои тематические подборки
-  **Локальное хранение** - все данные сохраняются в вашем браузере

## Старт

### Предварительные требования

- Node.js (версия 14 или выше)
- npm

### Установка и запуск

# Клонирование репозитория
```bash
git clone https://github.com/shelly-py/shellbook.git
```
# Переход в директорию проекта
```bash
cd shellbook
```
# Установка зависимостей
```bash
npm install
```
# Запуск приложения
```bash
npm start
```
